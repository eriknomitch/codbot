# Glossary

[← Back to index](README.md)

| Term | Meaning |
|---|---|
| **ADS** | Aim Down Sights |
| **Apex Attachment** | Special mod earned by maxing a gun. Changes how it works; doesn't use a slot. |
| **Ballistic Authority** | MW4's name for its gun system (no bloom, unified FOV, etc.) |
| **BlackCell** | Premium Battle Pass upgrade (included in Vault Edition) |
| **Bloom** | Random bullet spread when hipfiring. **Removed in MW4.** |
| **Boss Board** | DMZ FOB station to buy intel on bosses |
| **CaC** | Create-a-Class (custom loadouts) |
| **Classic / Regular Prestige** | Two Prestige paths: Classic resets unlocks for bonuses; Regular keeps unlocks |
| **Commander** | Roaming DMZ super-boss (Colossus, Deathstalker, Battle Tank) |
| **DMZ** | Extraction mode: loot, fight, and get out alive |
| **DMZ Cash** | In-game money used in DMZ only |
| **DMZ Orders** | DMZ mission list (tutorial, story, challenges) |
| **Dog Tag (DMZ)** | Shows an Operator's rank (Steel → Onyx III) and bounty level |
| **Dynamic Ops** | DMZ objectives that appear mid-match; each success gives a better Supply Drop |
| **Exfil / Infil** | Leave / enter the map |
| **FOB** | Forward Operating Base, your DMZ home base |
| **Gunny** | Auto-builder for weapon attachments |
| **Hajin** | The DMZ map (also Ground War maps and a Season 1 Warzone map) |
| **HVT** | High Value Target (Inflation mode, or a player carrying lots of cash) |
| **Kill Block** | Modular Multiplayer map that changes layout between rounds |
| **Lieutenant** | Elite DMZ boss tied to an area; drops a Dog Tag Case |
| **Marked for Death** | DMZ: you killed too many AI and a Hunt Squad is coming |
| **Meta** | The strongest weapons and loadouts right now |
| **MIA** | Missing in Action: a dead DMZ Operator who must be recovered with cash |
| **NVGs** | Night vision goggles |
| **POI** | Point of Interest (a named place on the map) |
| **Secure Slots** | Backpack slots that keep items even if you die (DMZ) |
| **Side Ops** | Small DMZ tasks (UAV towers, radio towers, SAM sites, trucks) |
| **Smartstreaks** | Killstreaks that fill from kills and objective play |
| **Stash** | Your DMZ storage at the FOB |
| **Threat Level** | DMZ danger meter for your area (Low → Extreme) |
| **Traits** | DMZ Operator perks (66 traits in 3 trees) |
| **TTK** | Time to kill |
| **Wanted** | DMZ: you've killed 4+ players and others are alerted |
| **X01** | Season 1 DMZ underground black site |
