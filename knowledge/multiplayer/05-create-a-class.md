# Create-a-Class: Perks, Equipment, Field Upgrades, Killstreaks

[← Back to index](../README.md)

**Create-a-Class unlocks at Player Level 4.** Before that, you pick from preset classes.
Each class has: **Operator, Primary, Secondary, Tactical, Lethal, Field Upgrade, 3 Perks, and Killstreaks.**

## Perks (Pick 3 — one from each slot)
